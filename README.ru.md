# NodeBB Integration

Слой интеграции NodeBB с AI-сервисами и MCP.

Плагин подключает NodeBB к семантическому поиску на базе искусственного интеллекта и предоставляет внешним AI-клиентам доступ к функциям форума через Model Context Protocol (MCP).

- **Версия:** 0.6.0
- **Лицензия:** MIT
- **NodeBB:** 4.x
- **Node.js:** >= 22

## Возможности

- MCP-сервер с транспортом Streamable HTTP.
- Отдельный дочерний процесс MCP под управлением плагина.
- Аутентификация MCP-клиентов по Bearer-токену.
- Отдельный токен аутентификации внутреннего API NodeBB.
- Настройка адреса прослушивания, порта MCP и сервисного аккаунта.
- 15 MCP-инструментов для получения информации о форуме, чтения, поиска и управления содержимым.
- Создание векторных представлений (embeddings) с помощью OpenAI и семантический поиск.
- Интеграция с векторной базой данных Qdrant.
- Фильтрация результатов с учётом прав доступа NodeBB.
- Индексация отдельных сообщений и исключение категорий.
- Режимы AI-провайдера OpenAI и Fake.
- Интерфейс настройки в NodeBB ACP.
- Автоматические тесты обработчиков API и MCP-инструментов.

## Требования

- Node.js >= 22.
- npm >= 10.
- NodeBB 4.x.
- Работающий экземпляр NodeBB.

Для семантического поиска дополнительно необходимы:

- API-ключ OpenAI.
- Доступный экземпляр Qdrant и настроенная коллекция, соответствующая используемой модели embeddings.

MCP может использоваться независимо от семантического поиска. Инструмент `search_knowledge` требует провайдера OpenAI и Qdrant.

## Установка

Установите плагин через интерфейс администрирования NodeBB или стандартным способом установки плагинов NodeBB.

При ручной установке:

```bash
cd /path/to/nodebb
npm install nodebb-plugin-integration
```

Соберите NodeBB и перезапустите его стандартным способом, предусмотренным вашей установкой.

После установки откройте:

**NodeBB ACP → Plugins → NodeBB Integration**

Настройте необходимые параметры и сохраните настройки.

## Настройка

Настройки плагина выполняются через NodeBB ACP.

### AI-провайдер

Поддерживаются два режима:

- **OpenAI** — включает embeddings и семантический поиск.
- **Fake** — отключает обращения к OpenAI. Семантический поиск в этом режиме недоступен.

Для семантического поиска настройте API-ключ OpenAI, параметры embeddings и подключение к Qdrant в соответствии с вашей инфраструктурой.

### Поиск и индексация

Плагин использует embeddings для индексации содержимого форума, а Qdrant — для хранения и поиска векторов.

Результаты не возвращаются только на основании векторного сходства. Перед выдачей результата плагин проверяет, может ли настроенный пользователь NodeBB читать соответствующее сообщение и тему.

Параметр Excluded Categories позволяет исключить выбранные категории из семантического поиска.

Плагин проверяет метаданные найденных сообщений по данным NodeBB перед возвратом содержимого. Qdrant используется как векторный индекс; источником содержимого сообщений и информации о правах доступа остаётся NodeBB.

### MCP-сервер

Настройки MCP:

| Параметр | Описание |
|---|---|
| Enable MCP | Включение и выключение MCP-сервера |
| Bind address | Адрес, на котором слушает HTTP-сервер MCP |
| Port | HTTP-порт MCP |
| NodeBB URL | Внутренний URL NodeBB для доступа процесса MCP |
| Bearer token | Токен аутентификации MCP-клиентов |
| Service user UID | NodeBB-аккаунт для проверок прав и операций записи |

Настройки подключения MCP по умолчанию:

```text
Bind address: 127.0.0.1
Port:         3100
NodeBB URL:   http://127.0.0.1:4567
```

Адрес `127.0.0.1` по умолчанию ограничивает доступ к MCP локальным интерфейсом. Меняйте его только при осознанной необходимости удалённого доступа и при условии защиты сетевого подключения.

Плагин автоматически генерирует отдельный случайный токен внутреннего API. Он отличается от Bearer-токена MCP-клиентов и не предназначен для передачи клиентам.

Настроенный сервисный пользователь является субъектом всех операций MCP. Клиент не может подменить UID пользователя, от имени которого выполняется операция.

## MCP-инструменты

MCP-сервер предоставляет 15 инструментов:

| Инструмент | Описание |
|---|---|
| `get_forum_info` | Получение общедоступной информации о форуме |
| `get_post` | Чтение сообщения |
| `get_topic` | Получение метаданных темы |
| `get_user` | Получение публичных полей профиля пользователя |
| `search_knowledge` | Семантический поиск по содержимому форума |
| `create_topic` | Создание темы |
| `delete_topic` | Логическое удаление темы |
| `restore_topic` | Восстановление темы |
| `list_topics` | Получение списка доступных тем |
| `create_post` | Создание ответа |
| `edit_post` | Редактирование сообщения |
| `delete_post` | Логическое удаление сообщения |
| `restore_post` | Восстановление сообщения |
| `delete_user_posts` | Пакетное логическое удаление ответов пользователя |
| `list_posts` | Получение сообщений темы |

Все операции записи используют нативные методы NodeBB и штатные проверки прав.

Инструменты удаления выполняют логическое удаление, а не безвозвратное уничтожение данных. `delete_user_posts` пропускает первое сообщение каждой темы. Восстановление темы не восстанавливает автоматически сообщения, удалённые отдельно.

Полное описание аргументов, схем, значений по умолчанию, ограничений, результатов, прав доступа, пагинации и примеров:

- [Справочник MCP API (Русский)](docs/MCP.ru.md)
- [MCP API Reference (English)](docs/MCP.md)

## Безопасность

- MCP-клиенты должны проходить Bearer-аутентификацию.
- Внутренний API NodeBB использует отдельный автоматически сгенерированный токен.
- Внутренние маршруты API требуют аутентификации и недоступны при выключенном MCP.
- Адрес прослушивания MCP по умолчанию — `127.0.0.1`.
- Права MCP-операций определяются настроенным сервисным пользователем.
- Операции чтения выполняют проверки доступа NodeBB.
- Семантический поиск фильтрует результаты с учётом прав сервисного пользователя.
- Публичный поиск пользователей возвращает только выбранные поля профиля.
- Секретные значения не включаются в публичную информацию о конфигурации плагина.

Используйте отдельную учётную запись NodeBB с минимально необходимыми правами. Не раскрывайте токен внутреннего API.

## Разработка

Установка зависимостей:

```bash
npm install
```

Проверка синтаксиса:

```bash
npm run check
```

Запуск тестов:

```bash
npm test
```

Тесты охватывают аутентификацию API, обработчики API, проверку аргументов и работу MCP-инструментов.
