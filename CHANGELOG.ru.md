# История изменений

## [0.6.1] - 2026-11-12

### Исправлено
- Исправлена обработка MCP API-запросов с пустым телом и методов GET/HEAD.
- Исправлено получение URL форума в `get_forum_info` через конфигурацию NodeBB.
- Исправлено получение языка форума в `get_forum_info`.
- Исправлено определение ID категории в `get_post` через данные связанной темы.
- Улучшена обработка отсутствующих и удалённых тем при получении сообщений.


Все значимые изменения проекта описываются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
проект придерживается принципов Semantic Versioning.

## [0.6.0] - 2026-11-11

### Добавлено
- Расширен MCP-сервер: теперь доступно 15 инструментов для работы с NodeBB.
- Добавлены операции создания и редактирования тем и сообщений.
- Добавлены операции мягкого удаления и восстановления тем и сообщений.
- Добавлено пакетное удаление сообщений пользователя.
- Добавлена постраничная выдача списков тем и сообщений.
- Добавлены тесты API и расширены тесты MCP-инструментов.

### Изменено
- Улучшена проверка прав NodeBB при выполнении операций через интеграцию.
- Улучшены проверка входных данных, авторизация и обработка ошибок в API-маршрутах.
- Улучшена работа с темами, сообщениями и пользователями NodeBB.
- Версия MCP-сервера обновлена до `0.6.0`.
- Обновлена документация для NodeBB 4.x и Node.js >= 22.

### Исправлено
- Улучшена обработка отдельных ошибок при пакетном удалении сообщений.
- Уточнена семантика метаданных пагинации: `hasMore` является оценкой на основе общего количества записей NodeBB и не гарантирует наличие результатов на следующей странице.
